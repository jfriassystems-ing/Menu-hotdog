# Menú Digital — D'Ambiorix Hotdog S.R.L.

Menú digital de comida con panel administrativo. Stack: HTML5 + CSS3 + JavaScript puro, Supabase (datos, auth, RLS), Cloudinary (imágenes), GitHub (repo), Vercel (deploy).

## Requisitos
- Cuenta en Supabase
- Cuenta en Cloudinary
- Cuenta en Vercel
- Node.js 18+ solo si vas a correr las Edge Functions localmente
